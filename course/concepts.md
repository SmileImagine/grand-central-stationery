# One idea from each element of music, in each piece

Generated by `course/concepts.js` from `course/set.json` (do not edit by hand; run `make concepts`). The data is `course/concepts.json`, which the piece view’s Listen step reads.

The elements are the six the Ontario curriculum’s Music strand names in every grade’s Fundamental Concepts box: duration (tempo is part of it), pitch, dynamics and other expressive controls, timbre, texture/harmony, and form. For each piece, one concept per element, with the grade that first names it, the bars that show it, and why. “All through” marks an idea heard in every bar; “new” marks the idea the piece brings into the course. A dash is an element the written music does not show. Bars count every written bar from 1, a pickup bar included.

Shown by the 0 pieces: duration 0, pitch 0, dynamics and other expressive controls 0, timbre 0, texture/harmony 0, form 0.
